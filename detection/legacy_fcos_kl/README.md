# FCOS-KL

The FCOS-KL configurations use [KLDet](https://github.com/TinyOD/mmdet-kldet) at commit [79caa41f16c84be8b9a6567002f51c2cad976f8d](https://github.com/TinyOD/mmdet-kldet/tree/79caa41f16c84be8b9a6567002f51c2cad976f8d).

| Component | Recorded version |
| --- | --- |
| Python | 3.8.20 |
| PyTorch | 1.10.2+cu113 |
| MMCV | 1.4.0 |
| MMDetection | 2.13.0, from the KLDet checkout above |

The RGB and panorama experiments used this environment. Add the KLDet checkout and this directory to `PYTHONPATH` so that the detector modules, `repair_guard` and `oldstack_adapters` can be imported.

```sh
export KLDET_ROOT="/path/to/mmdet-kldet"
export PYTHONPATH="$KLDET_ROOT:$PWD/detection/legacy_fcos_kl${PYTHONPATH:+:$PYTHONPATH}"
```

Use `configs/rgb.py` for RGB and `configs/panorama.py` for panorama. These configurations consume the annotations generated by the preparation commands in the repository README.

For panorama evaluation, retain `model.train_cfg` when constructing `FCOSAlignHead`. The recorded inference entry retains this assignment configuration. Convert the resulting tile predictions with `export_panorama_predictions.py` and evaluate them with `detection/panorama/merge_predictions.py` in the main detection environment.
